# App Đặt Trà Sữa & Cà Phê 🧋☕

Đồ án môn: Lập trình Mobile (React Native - Expo)  
Nhóm thực hiện: Nhóm 10 (Hồ Nhân Kiệt & Phạm Ngọc Duy)

## Công nghệ sử dụng
- **Frontend**: React Native, Expo, React Navigation (Tabs & Stack), Context API
- **Lưu trữ Offline**: AsyncStorage, SQLite (expo-sqlite)
- **Backend / Database**: PHP REST API, MySQL (XAMPP localhost)

## Hướng dẫn cài đặt & khởi chạy

### 1. Backend (XAMPP)
1. Import file `database/coffee_shop_db.sql` vào phpMyAdmin.
2. Copy thư mục `backend/coffee_api` vào `C:/xampp/htdocs/`.
3. Bật Apache và MySQL trong XAMPP Control Panel.
